###### Руководство пользователя

Система предназначена для хранения и совместной обработки данных о НИР, выполняемых
вузами по грантам, научно-техническим программам и тематическим планам. Пользователю
доступны просмотр исходных таблиц, база сводных показателей, отчетные формы,
фильтрация и упорядочивание данных, а также сохранение любой отображенной формы
в файл.

##### <a id="login"></a>1. Вход в систему

Приложение открывается в браузере. В форме входа вводятся логин и пароль, после чего
нажимается кнопка «Войти». При неверных данных выводится сообщение об ошибке и доступ
не предоставляется.

##### <a id="panel"></a>2. Панель управления

Панель расположена в верхней части экрана и содержит шесть кнопок:

- «Таблицы» - выбор исходной таблицы или базы сводных показателей, см. [раздел 3](#tables);
- «Анализ» - выбор отчетной формы, см. [раздел 4](#reports);
- «Фильтр» - задание условий отбора записей, см. [раздел 5](#filter);
- «Сортировка по ключу» - порядок вывода записей, см. [раздел 6](#sort);
- «Помощь» - настоящее руководство;
- «Выход» - завершение работы, см. [раздел 8](#exit).

Кнопки «Таблицы», «Анализ», «Фильтр» и «Сортировка по ключу» раскрывают список
вариантов. Список закрывается после выбора варианта или при щелчке вне его границ.

##### <a id="tables"></a>3. Просмотр таблиц и сводных показателей

Кнопка «Таблицы» открывает список из пяти исходных таблиц базы данных -
«Информация НИР по грантам», «Информации НИР по НТП», «Информация НИР по темпланам»,
«ВУЗы», «Рубрики ГРНТИ» - и, через разделительную черту, базы сводных показателей
«Сводные показатели».

База сводных показателей формируется по вузам и содержит количество НИР и объем
финансирования отдельно по каждой форме финансирования. Вузы, не выполняющие НИР,
в нее не включаются.

Справа от названия формы выводится общее число записей, отобранных по текущим
условиям [фильтра](#filter).

##### <a id="reports"></a>4. Отчетные формы

Кнопка «Анализ» открывает список отчетов, разделенный на две группы.

Отчеты по сводным показателям - распределение и финансирование НИР
«По субъектам федерации», «По городам», «По формам финансирования». Каждая строка
содержит количество НИР и объем финансирования: суммарные и отдельно по грантам,
НТП и темпланам. Последняя строка «Итого» содержит сумму по всем отобранным строкам.

Отчеты по базам НИР:

- «По руководителям, выполняющим более 1 НИР» - в отчет включаются руководители,
  за которыми закреплено не менее двух НИР в одном вузе. Однофамильцы из разных вузов
  считаются разными лицами;
- «По рубрикам ГРНТИ» - распределение НИР по рубрикам классификатора. НИР, имеющая
  два кода ГРНТИ, учитывается в каждой из двух рубрик; если оба кода принадлежат одной
  рубрике, НИР учитывается однократно. Итоговая строка в этом отчете не выводится,
  поскольку одна НИР может входить в несколько рубрик.

Все отчеты строятся с учетом условий [фильтра](#filter), заданных при просмотре.

##### <a id="filter"></a>5. Фильтрация данных

Кнопка «Фильтр» открывает окно с двумя группами условий.

Группа вузов - четыре списка: «Федеральный округ», «Субъект федерации», «Город»,
«Вуз». Значение «Все» отменяет условие по уровню. Уровни связаны: при выборе значения
на нижнем уровне верхние уровни заполняются автоматически. В списке предлагаются
только значения, допустимые при уже выбранных верхних уровнях.

Код ГРНТИ - три поля по две цифры, разделенные точками и соответствующие уровням кода.
Незаполненное поле обозначается знаками `**` и означает любое значение уровня.
Допускается ввод одной цифры: отбираются все коды, начинающиеся с нее. При вводе
букв или знаков выводится сообщение об ошибке, и условия не применяются. Если запись
содержит несколько кодов ГРНТИ, она отбирается при совпадении хотя бы одного из них.

Кнопка «Применить» устанавливает условия и закрывает окно, кнопка «Сбросить» отменяет
все условия. Условия действуют одновременно для всех форм - таблиц, сводных
показателей и отчетов - и сохраняются до их изменения или до выхода из системы.
Перечень действующих условий включается в [сохраняемый документ](#save).

Также для каждой таблицы поддерживается сортировка по столбцам. Чтобы воспользоваться
данной функциональностью, необходимо нажать на заголовок столбца.

##### <a id="sort"></a>6. Упорядочивание данных

Кнопка «Сортировка по ключу» задает порядок вывода записей: «Без сортировки»,
«По возрастанию» или «По убыванию». Упорядочивание выполняется по ключевым полям
отображаемой формы. Выбранный порядок действует для всех форм и сохраняется
до его изменения.

| Таблица | Информация НИР по грантам | Информации НИР по НТП | Информация НИР по темпланам | ВУЗы | Рубрики ГРНТИ | Сводные показатели | По субъектам федерации | По городам | По формам финансирования | По руководителям, выполняющим более 1 НИР | По рубрикам ГРНТИ |
|-----------|---|---|---|---|---|---|---|---|---|---|---|
| Ключевое поле  | Код конкурса и код НИР | Код НТП и код НИР | Код ВУЗа и код НИР | Код ВУЗа | Код рубрики | Код ВУЗа | Субъект федерации | Субъект федерации и город |Форма финансирования | Руководитель НИР | Код рубрики |

##### <a id="save"></a>7. Сохранение документов

Кнопка «Сохранить» расположена справа от названия отображаемой формы и доступна для
любой таблицы, базы сводных показателей и отчета. Документ формируется в одном из
четырех форматов: CSV, Excel, HTML, Word.

В имя файла включается название формы и действующие условия отбора. Документ
начинается с заголовка, содержащего название формы, перечень условий фильтра
(либо запись «Фильтр отсутствует») и общее число записей.

##### <a id="exit"></a>8. Завершение работы

Кнопка «Выход» завершает сеанс и возвращает систему к форме входа. Условия фильтра
и порядок сортировки при этом сбрасываются. Для продолжения работы требуется
повторный [вход в систему](#login).
