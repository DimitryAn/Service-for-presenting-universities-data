# Service for presenting universities data

Учебный проект: приложение для работы с базой данных вузов (SQLite).


## Запуск

1. Скрипт очистки данных. 
Все скрипты запускаются из корня проекта как модули, иначе не найдётся `config.py`.

```
python -m offline_scripts.clean_data
```

2. Сборка Docker-образа.
Сборка выполняется с помощью команды:
```bash
make build
```

3. Запуск Docker-контейнера. Старт выполняется с помощью команды:

```bash
make start
```

> [!NOTE]
> Приложение запускается на порту 8501.
> Старт выполняется с флагом `--rm`, что приводит к удалению контейнера после остановки.
